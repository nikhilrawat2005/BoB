3. FEATURES WITH WORKING IMPERFECTIONS & REQUIRED IMPROVEMENTS
====================================================================================================

Feature 1: System Prompt Overhead in Main Chat
• Problem: Every single message (even "hi" or "ok") sends ~1,200 tokens of static system instructions.
• Solution: Split system prompt into Modular Sections (Base System Prompt = ~350 tokens). Dynamically
  attach File Generator rules, Media rules, or Builder rules only when triggered by intent.
• Token Savings: Saves ~800 tokens per chat turn (30% to 40% reduction in chat cost).

Feature 2: Document Context Dumping (Large Files)
• Problem: Reading a 50-row Excel or 20-page PDF injects 10,000 - 40,000 characters (~3,000 to 10,000 tokens)
  all at once into the LLM context, which uses up token budget fast.
• Solution: Implement Smart Sectioning / Table Indexing: Send the table schema + top 10 relevant rows
  first, and fetch specific sheet chunks on demand.
• Token Savings: Saves ~3,000 to 6,000 tokens per document query.

Feature 3: Web Crawler HTML Noise
• Problem: crawlerService extracts page text but sometimes leaves navigation menus and footer links.
• Solution: Use aggressive Cheerio filtering to strip `<nav>`, `<footer>`, `<header>`, `.sidebar`, `.cookie-banner`.
• Token Savings: Saves ~800 to 1,500 tokens per URL scraped.

Feature 4: Instagram Reels Scraping Reliability
• Problem: Instagram public endpoints block IP requests intermittently without cookies.
• Solution: Add multi-source fallback (oEmbed + yt-dlp/rapidAPI fallback).

Feature 5: Background Memory Fact Deduplication
• Problem: If user mentions the same fact multiple times, memory collection grows with duplicate entries.
• Solution: Run cosine similarity / exact-match deduplication in memoryService before saving.
